# Archive

Everything the project did before it moved to one shared dataset of 14 paragraphs (`../dataset/`). Frozen: nothing here is
maintained. The folder is the **old repository root**: its layout is the one the scripts and READMEs expect, so to rerun
anything, `cd archive` first and use the commands as written there.

| folder | what | where to read the outcome |
|---|---|---|
| `prepare/` | PDF → canonical text (`texts/<doc>.json`) | `prepare/prepare_texts.py` (header lists the known limits) |
| `pilot/` | Alex and Claude: the LELA pilot on two paragraphs (35 mentions linked to YAGO 4.5), 12 LELA configurations, full-LLM baseline and hybrid | `pilot/README.md`, `pilot/results/summary.md` |
| `pilot14/` | the same approaches on the 14 paragraphs, with YAGO ids for their 83 entities (`entity_map.json`, now part of `dataset/gold`) | `pilot14/README.md` |
| `pipeline/`, `schema/`, `outputs/` | Lili and Max: NER (GLiNER, Jev), Wikidata linking, relation extraction (Jev, OpenIE), the YAGO schema and the history relations | `README_project.md` (the repository README before the restructuring) |
| `eval/` | the scorer `evaluate.py`, the 14-paragraph gold (Max) and all predictions `pred/<run>/` | `eval/README.md`, `eval/gold/README.md` |
| `experiments/` | 01–06 alias, Unicode, candidate analysis, Jev (Max, Lili); 07 NLI relations (Lili); 08 constrained-decoding relations (Alex) | `experiments/RESULTS.md`, each experiment's README |
| `README_RESULTS.md` | best models and metrics for each stage, as of November 2026 | itself |

## Notes
* **Paths:** with `archive/` as the root the commands work as written, for example
  `python experiments/08_constrained_relations/relations_constrained.py ...` or `python eval/evaluate.py ...`. The LELA runs
  also need the LELA clone and the YAGO 4.5 dump, which are no longer on disk (see the last note).
* **PDFs:** the papers are in `../dataset/articles/`. `prepare/prepare_texts.py` expects them in `papers/`; pass
  `--papers ../dataset/articles` (from `archive/`). The cleaned full texts (`texts/`) are git-ignored and regenerated by it.
* **What the results mean.** The main findings: GLiNER or an LLM for mentions (an LLM was better; Jev NER best of all), LELA
  alone links poorly (first candidate: link F1 0.14 on the 12 new paragraphs), an LLM that proposes a name and chooses from a
  YAGO shortlist is best at linking (0.53), the constrained LLM matches Jev API on relations without a threshold, Jev guided is
  best for relations (74.3 with a tuned threshold), NLI is weakest (40.0). Numbers on `p004` are biased: the pilot was developed
  on those two paragraphs. All numbers are against a draft gold that a historian has not reviewed.
* Kept out of the repository: the pilot's raw LELA output (`pilot/pred/`, git-ignored), the cleaned full texts and a PDF with
  speaker notes. The LELA clone and the YAGO dump are not part of the repository either.
